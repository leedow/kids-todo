# 实施检查清单

勾选表示已实现并完成相应验证；发布环境相关限制在末尾保留。每项均以真实接口和数据库作为输出，不以静态页面代替联调。

## P0 契约与交互

- [x] **P0-01**｜依赖：无｜输出：PRD角色、范围、奖励状态机｜验收：仅管理员/儿童，奖励不撤回、允许补领。
- [x] **P0-02**｜依赖：P0-01｜输出：架构、字段、约束、OpenAPI与API文档｜验收：前端类型由契约生成。
- [x] **P0-03**｜依赖：P0-01｜输出：页面流程与实际响应式界面｜验收：桌面/手机今日、选卡、图鉴和后台可演示。

## P1 工程与认证

- [x] **P1-01**｜依赖：P0-02｜输出：工程、配置、迁移、健康检查、Compose｜验收：空schema升级，真实库连接。
- [x] **P1-02**｜依赖：P1-01｜输出：Argon2id、Cookie会话、CSRF、初始化CLI｜验收：无默认密码，来源/凭证校验。
- [x] **P1-03**｜依赖：P1-02｜输出：多账号成员、上下文、单账号退出｜验收：账号并存且互不越权。
- [x] **P1-04**｜依赖：P1-03｜输出：登录、头像切换与独立后台布局｜验收：双标签页与延迟响应不串号。

## P2 任务

- [x] **P2-01**｜依赖：P1-02｜输出：三种重复规则与不可变版本｜验收：起止日期与星期组合。
- [x] **P2-02**｜依赖：P2-01｜输出：准备实例、历史还原、未来预览｜验收：重复准备唯一、历史不变。
- [x] **P2-03**｜依赖：P2-02｜输出：编辑、暂停、恢复、归档、完成/取消｜验收：今日同步，过去不可打卡。
- [x] **P2-04**｜依赖：P2-03/P1-04｜输出：表单、排序、今日时间轴｜验收：刷新持久化、多账号隔离。

## P3 内容

- [x] **P3-01**｜依赖：P1-02｜输出：分类、卡片集、卡片模型与归档｜验收：完整关联与历史限制。
- [x] **P3-02**｜依赖：P3-01｜输出：格式/大小/像素检查、WebP重编码｜验收：合法图片持久化，伪装和SVG被拒绝。
- [x] **P3-03**｜依赖：P3-02/P1-04｜输出：内容后台与12张原创卡｜验收：上传、权重、启停、图像预览。

## P4 奖励

- [x] **P4-01**｜依赖：P2-03｜输出：事务内资格与快照｜验收：非零全完成解锁一次，编辑与取消不撤回。
- [x] **P4-02**｜依赖：P4-01/P3-03｜输出：加权不放回候选和恢复｜验收：三张不同、刷新一致、卡池不足保留。
- [x] **P4-03**｜依赖：P4-02｜输出：原子获得记录和收藏UPSERT｜验收：并发选不同卡仅一份、故障回滚可重试。
- [x] **P4-04**｜依赖：P4-03/P2-04｜输出：三选一与待领取入口｜验收：补领、关闭恢复、明确确认后入图鉴。

## P5 图鉴

- [x] **P5-01**｜依赖：P4-03｜输出：收藏、数量、进度查询｜验收：重复卡增加数量，独特收藏不增加。
- [x] **P5-02**｜依赖：P5-01｜输出：图鉴、筛选、未解锁样式与详情｜验收：页面查询与真实获得一致。
- [x] **P5-03**｜依赖：P5-02｜输出：归档收藏与重建工具｜验收：下架仍保留记录，获得事实可重建。

## P6 日历与管理

- [x] **P6-01**｜依赖：P2-04/P4-04｜输出：月历、每日详情与奖励标识｜验收：42格月历和过去只读。
- [x] **P6-02**｜依赖：P1-03/P5-01｜输出：创建/编辑/禁用/密码重置和记录｜验收：禁用及密码重置撤销会话。
- [x] **P6-03**｜依赖：P6-01/P6-02｜输出：7/30天基础指标与趋势｜验收：任务、奖励所属日与领取日区分。
