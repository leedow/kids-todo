# 小小成长家 · 产品需求文档

## 目标和用户

面向家庭内4～12岁儿童。通过完成小任务积累卡片，让孩子看到持续行动的成果；低龄儿童由大人协助。首版只包含应用管理员与儿童账号，没有家长角色、公开注册和社交功能。

管理员维护账号、分类、卡片集、卡片和发放记录；儿童管理自己的任务、打卡、选卡和查看收藏。大人协助时使用对应儿童账号，不另设操作密码。管理后台不作为家长任务管理入口。

同一浏览器允许保留最多10个儿童账号的认证，切换无需再次输入密码；标签页独立选择账号。退出单个账号保留其他账号；管理员认证独立。

## MVP

| 优先级 | 功能 | 验收 |
|---|---|---|
| P0 | 登录、多账号切换、单账号退出 | 两个标签页可分别操作不同儿童 |
| P0 | 单次、每日、每周指定星期任务 | 规则由后端计算并持久化每日实例 |
| P0 | 今日时间轴、排序、暂停、恢复、归档 | 今天可打卡，过去只读，未来预览 |
| P0 | 每日奖励、三选一、补领 | 同一儿童同一天最多一次，不撤回 |
| P0 | 收藏、重复数量、图鉴进度 | 发卡和获得记录一致 |
| P0 | 账号、内容和记录后台 | 儿童无权进入 |
| P1 | 月历、基础7/30天统计、PWA | 不缓存账号API，不离线写入 |

首版全局卡池，四种稀有度，至少12张原创示例卡。稀有度仅作展示，抽样概率以卡片权重为准。

## 核心规则

1. 业务时区固定为 Asia/Shanghai。事件保存带时区时间，自然日为当地00:00至次日00:00，不包含结束边界。
2. 单次任务只在指定日期出现；每日和每周任务使用包含起止日的日期区间；每周使用1～7表示周一至周日。
3. 不能创建过去的任务。计划时间只提供提醒；过时仍可当天完成。未完成任务不自动滚入次日。
4. 每次编辑产生不可变任务版本。今日实例同步规则，过去实例不变；未访问历史按当日最后生效版本还原。
5. 暂停、归档或修改规则可让今日实例不参与计算，但保留记录。暂停可恢复并保留同日已有完成时间；归档不可恢复。
6. 今日有效任务数大于0且全部完成时，事务内创建唯一奖励并保存解锁依据。任务变化后重新判断，但不撤回已有奖励。
7. 无任务不产生奖励。解锁后取消完成、新增任务、归档任务均保留奖励，不再发第二份。
8. 已解锁奖励可跨天领取；过去的任务不能补打卡来解锁。当前完成情况与已解锁成就分别展示。
9. 候选正面直接展示，三张严格不同，允许抽到已拥有卡。第一次生成后永久固定，无重新随机入口。
10. 卡池不足三张时保留奖励，返回稍后领取。候选生成后卡片下架不影响选择。
11. 每份奖励最终只能产生一笔获得记录；重复获得同一卡增加数量，不增加独特收藏数。

## 权限与内容保存

儿童只能访问自己及当前会话已认证账号范围内的数据。客户端账号ID不是授权；必须由后端验证会话成员资格。卡片、分类和卡片集只能归档，不物理删除。图鉴显示当前资料，候选和获得记录保存当时快照。

仅采集用户名、昵称、预设头像、密码哈希及必要业务记录。不收集生日、真实姓名、学校、定位，不接入第三方广告或分析SDK。

## 统计口径

- 账号总数包含禁用儿童，禁用数量单列，不包含管理员。
- 活跃数为业务日执行儿童端认证请求的不同账号，不含管理端和健康检查。
- 应完成数为当日有效实例数；完成数为其中有完成时间的实例数；比率分母为零返回null。
- 奖励按所属业务日统计，发卡按实际获得的上海日期统计；补领不会改写奖励日期。
- 图鉴进度统计启用分类/卡片集中的启用卡片，按不同卡片计数。归档收藏仍可查看，不计当前进度分母。

## 后续

每隔N天、周视图、任务模板、家庭关系、公开注册与恢复、精细留存、偏好卡池、重复卡兑换、Capacitor App。均不作为首版隐含依赖。

## 产品取舍

采用信任式打卡，不验证任务是否真实完成；允许任务编辑意味着可以降低领奖门槛。系统保证记录与发放一致，不将此误称为防作弊。没有付费抽卡、倒计时、排行榜和连续打卡惩罚。
